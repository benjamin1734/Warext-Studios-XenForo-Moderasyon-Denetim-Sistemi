# Language support / Dil desteği

The add-on uses XenForo's native phrase/language system. Import the XML file under `languages/` into the corresponding XenForo language or a child language. Users switch language with XenForo's normal language selector and the audit UI follows automatically.

Audit evidence, staff-entered reasons, appeal text and other user/staff-generated content are not machine-translated; only system interface text is translated.

Yeni kullanıcıya görünen sabit metinler phrase kullanılmadan PHP/template/JS içine eklenmemelidir.
